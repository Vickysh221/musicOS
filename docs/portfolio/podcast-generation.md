# 把"血缘"做成播客：一档自用的生成式节目

起因很私人。我在听歌、练琴的时候反复想知道这首歌在音乐史里受过谁的影响、属于哪个母题、又启发了谁；也想知道那份几千首的红心歌单里，别的歌和它之间是不是有牵连，我还没拓展的版图在哪里。市面上的音乐软件能基于大数据给我推相似歌，但它不会一开始就告诉我为什么推。我要的不是相似，是**血缘**。

## 把"血缘"作为推荐的目标函数

相似是降维之后的距离，血缘是叙述里的因果。一个回答"它和它差不多"，一个回答"它从哪里来、长成什么、又传给了谁"。整套生成系统都围着血缘这条目标函数转：

- **读完用户的红心**：先把几千首歌作为用户的音乐画像来读。
- **挑值得探索的几条线**：从画像里抽出最具叙述潜力的若干条血缘线索，不是热门 cluster，是有故事可讲的母题或断代节点。
- **围绕一条线做一期节目**：每一期是一条血缘的展开。曲目是论据，转写稿是叙述。

## 两条入题路径

一档节目可以从两端被发起：

1. **AI 出题。** 系统看到我最近反复在听 Estranged，反推一道题给我："双主角，人声和吉他能不能同时占据前景。"这是用我的听歌行为，挖出一个我自己还没自觉到的兴趣。
2. **我出题。** 我对它说"我想听 Miss You，沿着 bassline 的 DNA 往外走"，它生成一期十八站、跨五十七年的节目。我给入口和方向，它把版图填出来。

两条路径背后是同一套数据线：用户画像 + 主题 + 曲目谱系 + 转写稿。区别只在谁先开口。

## 落地后的副作用：注意力

这是我这几个月第一次全神贯注听完一整集节目。这件事的解释很朴素：它真的和我在探讨**我自己的**音乐。它带我听吉他的诉说、贝斯的低语；那些是从我的红心里被它挑出来的线，经过它的整理回到我面前，所以我没有走神的余地。

注意力是一个产品很难买回来的东西。生成式节目能买回来，是因为它不是"内容"，是"对话"。

## 关于口吻

AI 用的是一种特定的口吻：不打招呼、不卖人设、不暖场，进来就是一段叙述。具体规范留在另一篇文档展开。
